# QQ Agent 脑洞社区

一个无聊测试脑洞的小网站，任何人都能来逛、来投稿。

> 你们这些拉屎的非主流能不能从官方群滚出去，没人会欢迎你们的
>
> 没事，来妈妈这里，这里收容你

---

## 这是什么

这里收集大家分享的 QQ Agent 玩法，按三种类型分类摆放：

- 🎭 **人设** —— 你给 Agent 捏的性格、说话风格、背景故事
- 🧩 **插件** —— 给 Agent 加的新功能模块
- 🛠️ **技能** —— 教 Agent 做某件事的本领

每一条投稿都带一段文字介绍，有的还会附上下载 / 查看链接，点链接就能拿到。

---

## 怎么逛

打开首页，顶部有三个分区按钮（人设 / 插件 / 技能），点哪个就看哪个。
每个分区右上角会显示当前有几条内容，卡片按发布时间从新到旧排列。

看到喜欢的直接点卡片里的链接下载或查看；内容太长会折起来，点“展开”看全文。

---

## 怎么投稿

1. 点右上角 **「✍️ 我要投稿」**
2. 选择你要投的类型：人设 / 插件 / 技能
3. 会跳转到 GitHub 的投稿页面，填好：
   - **标题** —— 给你的脑洞起个名字
   - **文字介绍** —— 说明它有什么用、怎么用
   - **下载 / 查看链接** —— 可选，必须是 http 或 https 开头的网址
4. 提交

> 投稿需要 GitHub 账号，提交后自动进入“待审核”队列，不会立刻显示。

---

## 审核规则

投稿由管理员人工审核：

- ✅ 内容不错 → 打上「已通过」标签，网页 1 分钟内自动显示
- ❌ 不合适 → 直接关闭，不会出现在网页上
- 🗑️ 已经通过的也可以随时下架

所以**没通过审核的内容是看不到的**，审核通过后刷新网页就能看到。
